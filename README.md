# Divyanshi's Birthday Website 💗
Run: `npm install && npm run dev` (open the printed localhost link). Build: `npm run build` (output in `dist/`).
Edit text: `src/data/birthdayContent.js`. Photos: put files in `public/images/birthday/` and list them in `src/data/birthdayPhotos.js` (missing files show a placeholder).
Music (optional): put your own file at `public/music/birthday.mp3`; without it the controls simply hide after a failed play.
Deploy: run `npm run build`, then drag the `dist` folder onto https://app.netlify.com/drop (or push to GitHub and import into Vercel / Netlify) to get a shareable link.
